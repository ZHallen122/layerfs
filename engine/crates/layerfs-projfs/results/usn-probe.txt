# What this shows:
# - A placeholder is created as a sparse reparse point (0x200 | 0x400) and stays one after
#   hydration (0x620). The provider's own process sees neither attribute ("now attrs=0x20").
# - A tombstone is a hidden system reparse point (0x426) and cannot be opened by identity while a
#   provider runs (error 2). A deleted name leaves one in a projected directory, also when the
#   deleted file was a full file. The provider's own listing does not show a tombstoned name.
# - A change of the read-only attribute is a BASIC_INFO record, on a placeholder too.
# - The first write through a handle is a record; a second write through the same handle is not.
# - A directory keeps its identity when renamed, so a file below it is found at its new path.
